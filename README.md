# EKT Copilot — Creepers / HackAlem AI 2026

Рабочее пространство закупщика для кейса ТОО «Электрокомплект». Один диалог объединяет поиск товара, проверку характеристик и наличия, подбор объяснимых альтернатив и подготовку корзины **после явного подтверждения**.

## Запуск за несколько минут

Требования: Python 3.12+, Node.js 22, npm. Команды выполняются из корня репозитория в PowerShell.

```powershell
py -3.12 -m venv Backend/.venv
Backend/.venv/Scripts/python.exe -m pip install -r Backend/requirements.txt
cd Frontend
npm ci
cd ..
./start.ps1
```

- Реальный каталог: <http://localhost:3000>
- **Автономное демо для жюри:** <http://localhost:3000/?mode=demo> — без аккаунтов и ключей.
- API: <http://127.0.0.1:8000/docs>
- Логи запуска: `.local/`. Скрипт не останавливает уже работающие процессы.

Альтернатива: два терминала, `cd Backend` → `.venv/Scripts/python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --no-access-log`; `cd Frontend` → `npm run dev`. Для демонстрации используйте один backend worker. Корзины хранятся в памяти и сбрасываются при перезапуске.

## Данные и ключи

Для реального каталога создайте `Backend/.env` из `Backend/.env.example`, если файла ещё нет, и локально заполните `EKT_API_PASSWORD`. Логин — `apiuser`, URL — `https://ekt.kz/api`. Уже существующий `.env` не перезаписывайте. Пароли и ключи нельзя добавлять в Git или браузерный код.

API EKT доступен только backend. `/products` используется для ограниченного поиска по страницам, `/products/detail?id=…` — для актуальных характеристик и остатка. Неизвестные цена, валюта, остаток и сертификаты остаются неизвестными. Конфликтующие параметры явно показываются. Изображения и ссылки на товар берутся из EKT. Кэш страниц — 60 секунд, детальные данные обновляются перед добавлением. По умолчанию поиск охватывает первые 5 страниц, а не весь каталог; интерфейс это отмечает.

Учебный режим использует **отдельные** синтетические товары `900001–900005` и отдельные сессии. Он включается только явно, никогда автоматически после ошибки EKT. Учебный сертификат помечен как демонстрационный и не является документом соответствия.

Оплата и доставка описаны по [официальному FAQ EKT](https://ekt.kz/about/faq/), проверенному 23.09.2026. Неуказанная единая минимальная партия не выдумывается. Тарифы и окончательные условия подтверждает менеджер.

## Нужен ли AI-ключ?

**Для основного демо, каталога и корзины — нет.** Для дополнительного понимания свободных запросов на русском/казахском и распознавания маркировки на фото добавьте локально в `Backend/.env`:

```dotenv
OPENAI_API_KEY=
OPENAI_MODEL=gpt-4o-mini
```

Заполните значение ключа и перезапустите backend. Это отдельный ключ OpenAI API; пароль EKT его не заменяет. Без ключа включены детерминированные сценарии. При ошибке модели они остаются доступны. Модель используется для нераспознанных запросов, а не для генерации цен и наличия. Полного свободного диалога и казахской локализации интерфейса пока нет.

Модель возвращает только проверяемое намерение чтения через [Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs). Она **не может подтвердить корзину**. Факты извлекаются сервисами из каталога. Нераспознанный текстовый запрос передаётся OpenAI только при настроенном ключе; `store:false`. Фото отправляется только при включённом пользователем флажке «Распознать фото через OpenAI», в реальном режиме. Использован [Responses API с изображениями](https://developers.openai.com/api/docs/guides/images-vision). Реальный вызов модели требует вашего действующего ключа; без него интеграция проверяется подменённым HTTP-ответом.

## Что проверить в интерфейсе

1. Откройте `/?mode=demo` и нажмите «Проверить наличие»: товар `900001`, 24 единицы, характеристики и учебный документ.
2. Укажите 2 единицы → «В корзину». **Корзина остаётся пустой** до «Да, добавь 2».
3. Нажмите подтверждение → откройте корзину → скачайте список. Перезагрузка страницы сохраняет корзину, пока живёт серверная сессия.
4. Нажмите «Найти замену» или отправьте `товар 900003`: нулевой остаток, аналоги с объяснением совпадений. Автомат на 40А не предлагается как замена 25А.
5. Подготовьте ещё одно добавление → «Отмена» → отправьте `да, добавь`: отменённое действие не выполняется.
6. Запросите `добавь 100 штук`: превышение остатка блокируется на сервере.
7. Откройте раздел оплаты и доставки; задайте те же вопросы в чате.
8. Загрузите XLSX/DOCX/текстовый PDF: проверьте текст и выберите строку для поиска. Инструкции внутри файла не меняют корзину.
9. Переключитесь на реальный каталог: `товар 515282`. Данные приходят из EKT, синтетическая корзина изолирована.

## Вложения

Принимаются XLSX, DOCX, PDF, JPEG/PNG и старые XLS/DOC, до 10 МБ. XLSX/DOCX и текстовые PDF читаются в памяти: до 6000 символов, 5 листов, 10 страниц. ZIP ограничен суммарным распакованным размером 20 МБ и 1000 элементами. Формулы и макросы не исполняются. Файлы не сохраняются на диск. Полученный текст нужно проверить и явно использовать для поиска — импорт не добавляет товары автоматически.

Фото до 4 МБ: опциональное AI-распознавание видимой маркировки после включения флажка и подключения ключа. Модель может ошибаться. Старые XLS/DOC, сканы PDF, зашифрованные и нераспознанные документы пока требуют ручного ввода или конвертации в поддерживаемый текстовый формат. PDF-парсер ещё не изолирован отдельным процессом: публичная обработка произвольных документов требует дополнительного усиления.

## Архитектура

```text
Next.js / React (чат, каталог, корзина, вложения)
  └─ same-origin /backend proxy
     └─ FastAPI
        ├─ классификатор → optional OpenAI → read-only catalog tools
        ├─ EKT client → нормализация → поиск / аналоги / свежие остатки
        ├─ prepare → pending → explicit confirm → cart
        ├─ session lock + TTL → изоляция и защита от двойного добавления
        └─ /demo/api → автономный каталог и отдельное хранилище сессий
```

Случайный UUID сессии хранится в браузере отдельно для каждого режима. Ссылка на корзину — bearer-ссылка: знающий её получает доступ к сессии. Она не является авторизованным аккаунтом. TTL — 1 час бездействия, подготовленное добавление — 5 минут. Сессии ограничены по количеству. Платёжные данные не собираются.

**Граница MVP:** это локальная корзина прототипа. Заказ в ekt.kz не создаётся, товар не резервируется. Настоящий checkout требует согласованного с EKT API, авторизации и серверной интеграции. До публичного SaaS нужны tenant isolation, авторизация, серверное хранилище, rate limits, квоты AI, аудит, изоляция обработчиков файлов, HTTPS и тестирование под нагрузкой. Производственных клиентов, выручки и доказанного процента экономии времени пока нет.

## Проверки

```powershell
cd Backend
.venv/Scripts/python.exe -m pytest -q
.venv/Scripts/python.exe scripts/check_workspace.py
cd ../Frontend
npm run lint
npm run build
```

`check_workspace.py` требует запущенные frontend/backend и проверяет цепочку через Next.js proxy, включая ссылку на корзину, отмену и превышение остатка. Основные тесты backend не требуют сети или ключей. Для реального EKT отдельно доступен `Backend/scripts/inspect_ekt.py`.
